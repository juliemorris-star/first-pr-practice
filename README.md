# First PR Practice

A tiny sandbox repo for practicing the GitHub pull request workflow.

## What this is

This repo exists so you can experience the full loop: make a change, push a branch, and open a pull request.

## Getting started

Clone the repo and take a look around. There's not much here yet.

## Contributing

1. Fork or clone the repo.
2. Create a branch for your change.
3. Open a pull request describing what you changed and why.
